### 👋 Hi, I'm Ngô Đức Việt

Open-source developer from **Việt Nam** 🇻🇳 — I turn **ESP32 + Home Assistant** into real products.

Building premium Home Assistant integrations & ESP32 IoT devices for smart homes worldwide.

---

#### 🔆 [Lumentree HA](https://github.com/ngoviet/lumentreeHA) — Solar inverter monitoring for Home Assistant
Real-time MQTT monitoring, energy stats (daily/monthly/yearly/total), battery management, PV power tracking. HACS compatible. MIT licensed.

#### 📡 [MikroTik HA](https://github.com/ngoviet/mikrotik-ha) — RouterOS integration for Home Assistant
26 languages, 3 releases, Apache 2.0. Monitoring, NAT rules, PPPoE status, firewall tracking.

#### 🔌 [SmartSolar HA](https://github.com/ngoviet/smartsolar-ha) — MPPT solar charge controller integration
Manh Quan 40A/45A/60A WiFi charger monitoring for Home Assistant.

#### 🌀 [ESP32 BLDC Smart Fan](https://github.com/ngoviet/esp32-esphome-bldc-smart-fan)
Variable-speed fan controller with CLK frequency control, EC11 rotary encoder, native HA integration.

#### 🔮 [ESP32-C6 Matter Fan](https://github.com/ngoviet/esp32-c6-matter-fan)
Matter-compatible smart fan using ESP32-C6. First step toward Matter smart home products.

#### 💡 [ESP32 Smart LED Control](https://github.com/ngoviet/esp32-smart-led-control)
Modular ESPHome architecture with BME280, motion detection, intelligent automation.

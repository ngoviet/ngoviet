**English** · [Tiếng Việt](README.vi.md)

Open-source developer from **Việt Nam** 🇻🇳 — I build **Home Assistant integrations** and **ESP32 / ESPHome devices**

#### Lovelace cards and themes

- [**LAN Topology Card**](https://github.com/ngoviet/lan-topo-card) — live LAN map (Internet → router → switches → ports) with traffic-animated links; MikroTik, Netgear Plus or manual ports.
- [**Palette AXI Neon**](https://github.com/ngoviet/palette-axi-neon) — dark neon theme: night-blue surfaces, accents on one OKLCH lightness band, readable text fields.

#### ESP32 / ESPHome devices

- [**BLDC Smart Fan**](https://github.com/ngoviet/esp32-esphome-bldc-smart-fan) — variable-speed BLDC fan with CLK frequency control and EC11 rotary encoder.
- [**JK-BMS Monitor**](https://github.com/ngoviet/esp32-jk-bms-monitor) — JK-BMS 24V 280Ah battery monitoring over ESP32.
- [**48V BMS Monitor + Fan Control**](https://github.com/ngoviet/esp32-jk-bms-48v-fan-control) — JK-BMS monitoring with temperature-based cooling fan.
- [**12V Auto Power Switch**](https://github.com/ngoviet/esp32-auto-power-switch-12v) — switches power source based on battery SOC from Home Assistant.
- [**Smart LED Control**](https://github.com/ngoviet/esp32-smart-led-control) — modular ESPHome LED controller with BME280 and motion detection.
- [**ESP32-C6 Matter Fan**](https://github.com/ngoviet/esp32-c6-matter-fan) — *experimental* Matter smart fan on ESP32-C6.

#### Tools

- [**mikrotik-axi**](https://github.com/ngoviet/mikrotik-axi) — inspect and safely operate MikroTik RouterOS v7 over REST; a CLI built for AI agents.
- [**Local LLM on CPU**](https://github.com/ngoviet/local-model-cpu) — Gemma MoE + vision with llama.cpp, 256K context, ~11.5 tokens/s on an i5 mini PC.
- [**YouTube Bilingual Subtitles**](https://github.com/ngoviet/yt-sub) — Chrome extension: real-time bilingual subtitles, transcript panel, SRT/VTT export.
